# 铺记 2.0 更新说明

> 适用范围：本次推送包含自 `origin/main`（2026-09-06）以来的全部成果，即 **Android 2.0 重构** 与 **HarmonyOS 原生版** 两条线。
> 可直接用作 GitHub Release 正文。

版本：`2.0.1`（versionCode `7`）· 包名 `cn.puji.app` · Android 8.0（API 26）及以上 · 数据库版本 `3`

---

## 一句话概括

铺记从「能用的扫码记账工具」变成了「账目对得上、数据丢不了的小店经营本」：界面整体重做为米白轻排版，库存引入可解释的成本账本与纠错路径，并补上完整备份、商品导入和新的 App 图标。

## 界面与品牌

- 全新米白视觉：底色 `#F6F2E9`、奶白卡片、灰蓝主色 `#365D6C`，去掉英文小标题、粗黑字与装饰性说明。
- 统一紧凑排版：页标题 22sp、正文 15sp、重点金额 26sp，支持深色模式与系统大字体；触控区域不小于 48dp。
- 四栏结构收敛为 今日 / 商品 / 扫码 / 经营，数据管理入口移入设置。
- 新 App 图标：色片拼贴的小店图案，含自适应图标、单色图标及各密度 PNG。
- 2.0.1 修复分发平台图标问题：应用元信息改为直接指向可提取的 PNG，桌面图标仍使用自适应资源。

## 库存账本（本轮最大变化）

- 商品资料编辑不再直接改库存；库存变动只通过期初、入货、出货、盘点、报损产生，每次都有留痕。
- 新增期初库存、盘点、报损、原单部分退货与冲正；原始单据不可修改或删除，错单走关联纠错。
- 移动平均成本：库存总成本按实际进货与现存数量分摊，最后一件消耗尾差；成交时写入成本快照，改建议进价不影响历史利润。
- 报表口径明确区分净销售、净采购、毛利润与进销差额，报损、盘亏、估值差额单列。
- 全部写入走事务，库存不为负；重复提交由请求 ID 去重。

## 扫码与清单

- 支持多商品连续扫码、手工输入条码、搜索选货，可改数量、单价与备注。
- 同一码持续停留不会重复加件，移开后再次识别正常；提交期间禁用扫码。
- 未知条码可当场建档，与本次入货一起提交。
- 清单本地草稿：切后台、重开应用后数量与价格恢复；切换入货/出货会提示保护现有清单。

## 备份、导入与导出

- 完整备份 `.puji.json`：包含四张业务表全部字段、版本与校验信息；恢复先验证再事务替换，失败回滚。
- 冷启动自动生成当日副本，轮换最近三个日期，替换前保留一份回退副本。
- 商品 CSV 预览导入：先校验再确认，同条码只更新资料、保留库存与成本，新商品走期初，整体成功或回滚。
- 库存与流水 CSV 导出；流水的搜索与日期/类型筛选同样作用于导出。

## 升级与数据安全

- 覆盖安装即可，旧版商品、库存、单据与成本快照全部保留；数据库迁移不清空数据。
- 与 1.1.1 签名证书一致（SHA-256 `a0f5dfb7…5cb2`），请勿用卸载方式处理签名问题。
- 完整备份不能替代：本机副本与 CSV 都不防卸载或设备丢失，请定期把 `.puji.json` 存到手机之外。

## 同仓库的 HarmonyOS 版

`harmony/` 是同一业务的 HarmonyOS Stage 模型原生实现，与 Android 数据彼此独立，本轮未与其同步改动。

- ArkTS / ArkUI / ArkData，DevEco Studio 26.0.0，SDK 6.0.2（API 22），兼容 HarmonyOS 5.0.0（API 12）。
- 已实现：经营概况与低库存提醒、商品货架与筛选搜索、Scan Kit 扫码与手工输入、入货/出货购物车与库存校验、未知商品扫码暂停、月度/季度/年度汇总、按月流水与自定义日期 CSV 导出。
- 产物为未签名 HAP；安装到设备需自行登录华为开发者帐号完成调试签名，签名材料不入库。

## 已知限制

- 实体机摄像头连续扫码、不同厂商相机与 Android 8 实体机尚未实测；控制器规则已由自动测试覆盖。
- 不含云同步、多门店、员工权限、支付、打印、供应商与赊账；已预留 UUID 与仓库边界，但本版无联网能力。
- 不支持称重与箱件换算；金额为整数分，库存为整数件。
- 鸿蒙包未做发布签名，也未与 Android 端数据互通。
