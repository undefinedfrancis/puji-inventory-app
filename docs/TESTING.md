# 铺记 v1.0.0 测试与验收

## 自动化测试

单元测试覆盖：

- 金额解析、格式化和非法精度；
- 购物车同商品合并、加减数量、进售价选择与合计；
- 入货/出货库存规则和负库存拦截；
- 重复扫码节流；
- 商品表单验证；
- 库存与流水 CSV 的中文、逗号、引号、换行及 BOM 处理。

Android 数据库测试覆盖：

- 入货增加库存、出货扣减库存；
- 单据及商品名称/价格快照保留；
- 条码唯一约束；
- 多商品出货单的今日销售额不重复累计。

## 已完成模拟器验收

- Android 16 / API 36.1 模拟器安装并启动成功；
- 首页显示今日统计、库存预警和快捷入货/出货；
- 库存页显示示例商品、价格与余量；
- 相机权限允许/拒绝流程正常，拒绝后仍可手工录入；
- 输入已知条码 `6901234567890` 可识别“可口可乐 500ml”并带出售价；
- 确认出货后库存扣减，记录页生成对应出货单；
- 全量单元测试、Android 数据库测试、Android Lint 和 Debug/Release 构建作为发布门槛执行。

## 发布检查

最终 APK 需要满足：

- 包名：`cn.puji.app`
- 版本：`1.0.0`（versionCode 1）
- 最低系统：Android 8.0 / API 26
- Release APK 可安装、可启动、签名校验通过
- SHA-256 记录在最终交付信息中
