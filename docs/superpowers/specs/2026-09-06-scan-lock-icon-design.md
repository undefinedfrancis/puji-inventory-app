# 铺记扫码交易锁与图标改版设计

## 目标

解决商品建档弹窗打开后摄像头仍继续识别、导致弹窗内容反复变化的问题，并替换辨识度较弱的旧图标。

## 扫码状态设计

扫码流程增加独立的 `ScanTransactionGate`：

1. 空闲状态接受第一个非空条码后立即进入锁定状态。
2. 锁定状态拒绝相机和手工输入产生的后续条码。
3. UI 在锁定时移除 `CameraContent`，触发 CameraX 解绑和分析器关闭，而非只隐藏识别结果。
4. 已知商品加入当前清单；未知商品打开建档弹窗，保存后加入当前清单并继续保持锁定。
5. 只有数据库交易提交成功后才解除锁定并重新创建相机；提交失败仍保持锁定，供用户修正。
6. 用户取消未知商品建档，或将当前清单最后一件商品移除，视为取消本次扫描并解除锁定。

## 图标设计

采用 Android 自适应矢量图标：深森林绿背景、米白购物袋主体、袋内四段条码和一条橙色扫描线。图形集中在安全区域内，不使用文字、渐变、阴影或细碎装饰，并提供 monochrome 图层以适配 Android 主题图标。

## 验证

- 单元测试覆盖首次接受、锁定期间拒绝、交易成功恢复、取消恢复和空条码。
- 模拟器验证条码加入后出现“扫描已暂停”，输入框不可用；确认出货后恢复“等待第一件商品”。
