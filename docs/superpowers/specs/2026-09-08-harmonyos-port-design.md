# 铺记 HarmonyOS 原生版设计

## 目标

为现有 Android 版“铺记”增加一套独立的 HarmonyOS 原生应用，使其可运行在 HarmonyOS NEXT／HarmonyOS 5.0.0 及以上手机和平板。鸿蒙版保留当前铺记的核心业务能力、四栏信息架构和视觉语言，同时不改动现有 Android 工程和 APK。

首个可交付版本为可在鸿蒙模拟器验证的 Debug HAP。若需要安装到真实设备或提交华为应用市场，再使用用户自己的华为开发者账号完成自动签名或发布签名。

## 已确认的产品决策

- 使用 ArkTS、ArkUI 和 Stage 模型原生开发，不采用 Android 兼容层。
- 在仓库根目录新增 `harmony/` 独立工程，现有 Android 工程保持原样。
- 应用名称继续使用“铺记”，鸿蒙包名使用 `cn.puji.app`。
- 最低兼容版本为 HarmonyOS 5.0.0(12)。
- 使用当前正式版 DevEco Studio 26.0.0 和 HarmonyOS 26.0.0 SDK 编译。
- 首版保持离线、单机、本地存储，不增加账号、云同步或多门店。
- Android 版与鸿蒙版的数据彼此独立；本次不实现跨系统数据迁移和 CSV 导入。

## 工程结构

鸿蒙工程采用一个 `entry` HAP 模块，并按职责拆分：

- `model/`：商品、入出货单、明细、经营统计和日期范围等纯数据模型。
- `domain/`：金额计算、购物车、库存变更、周期计算、扫码交易门闩等纯业务逻辑。
- `data/`：ArkData 关系型数据库初始化、升级、查询和事务。
- `scanner/`：Scan Kit 初始化、相机权限、扫描结果去重、暂停与恢复。
- `export/`：库存和流水 CSV 生成、文件保存及系统分享。
- `pages/`：首页、货架、扫码、经营记录和流水明细页面。
- `components/`：按钮、指标卡、筛选标签、商品卡、弹窗及空状态等复用组件。
- `theme/`：铺记颜色、字体、圆角、间距和图标资源。

页面只负责展示与接收操作，数据库读写和计算集中在独立服务中。页面之间通过明确的应用状态和导航参数通信，避免将数据库操作散落在 UI 组件内。

## 页面与功能

### 首页

- 展示今日销售额、今日出货件数、商品数量、库存成本和低库存提醒。
- 提供“扫码出货”“登记入货”和“查看货架”快捷入口。
- 页面底部保留“重置全部数据”，先显示风险说明，再要求按住 2 秒确认。
- 重置在一个数据库事务中完成；失败时回滚并保留原数据。

### 货架

- 支持新增、编辑、搜索、停用和查看商品。
- 商品字段包括名称、条码、类别、进价、售价、库存、低库存阈值和备注。
- 类别筛选与关键词搜索可叠加；“全部”模式按类别分组。
- 支持导出完整库存 CSV。

### 扫码与交易

- 使用 HarmonyOS Scan Kit 自定义扫码界面，以保持铺记的品牌界面和连续作业体验。
- 支持常见商品条码，包括 EAN、UPC、Code 39/93/128、ITF、QR 等 Scan Kit 可识别码制。
- 扫描成功后立即停止接收新的识别结果，并锁定扫码状态。
- 已建档商品加入当前入货或出货清单；重复扫码合并数量。
- 未建档商品打开资料表单。入货模式下填写“本次入货数量”并确认后，一次性建立商品、写入入货单和增加准确库存，不再要求第二次添加。
- 商品确认、交易提交或用户明确取消后才恢复扫码。
- 出货时校验库存；库存不足不写入任何记录。
- 相机权限不可用或 Scan Kit 不可用时，保留手动输入条码入口。

### 经营记录

- 按月度、季度和年度查看销售收入、进货支出、毛利润、现金结余、毛利率和交易笔数。
- 趋势图按日或按月聚合收入与支出。
- 流水明细支持按月份以及全部、入货、出货类型筛选。
- 单笔流水继续保持不可修改、不可删除。
- 支持导出当前月份流水和自定义日期范围流水。

## 数据模型与存储

鸿蒙版使用 ArkData `relationalStore`，数据库文件名为 `puji.db`。表结构与 Android 版保持同一业务含义：

- `products`：商品资料和当前库存。
- `documents`：入货或出货单据。
- `document_lines`：单据商品明细、成交单价和成本快照。
- `stock_movements`：每次库存变化及变更后的库存。

金额全部使用整数“分”保存，避免浮点误差。日期使用 Unix 毫秒时间戳，查询统一使用左闭右开的自然时间范围。

入货、出货和重置均使用数据库事务：单据、明细、库存和库存变更必须全部成功才提交。所有外部输入通过参数化查询写入数据库，不拼接 SQL。

首次安装保留三条可编辑演示商品，和 Android 版保持一致。卸载应用会清除本地数据，因此页面需要持续提示用户定期导出 CSV。

## 状态与数据流

1. 页面发起查询或业务操作。
2. 页面状态对象调用对应仓库或领域服务。
3. 仓库通过 ArkData 读取或在事务中写入数据。
4. 成功后统一刷新首页、货架、经营统计和流水；失败时不改变已展示的业务状态，并给出中文提示。

扫码使用独立状态机：`等待扫码 → 已识别并锁定 → 商品确认/交易确认 → 恢复扫码`。任何页面重组、弹窗显示和异步回调都必须检查当前状态，确保一个识别结果最多生成一次业务操作。

## CSV 与系统分享

- CSV 使用 UTF-8 BOM，确保中文表格软件可直接打开。
- 库存导出包含商品资料、进售价、库存和状态。
- 流水导出包含日期、单号、类型、商品、条码、数量、单价、成本、金额和毛利润。
- 文件先写入应用缓存目录，再通过 HarmonyOS 系统分享能力交给用户选择目标应用。
- 选定范围没有数据时不生成空文件。

## 错误处理

- 数据库初始化失败时显示不可继续操作的错误页，并提供重试入口。
- 数据库事务失败时回滚，不允许库存与流水不一致。
- 相机权限被拒绝时解释用途，并保留手动条码入口。
- 扫码失败、取消或识别到空内容时返回可继续扫描状态。
- 导出或分享失败时保留原数据并显示可理解的错误提示。
- 所有异步操作设置执行中状态，防止重复点击和重复提交。

## 开发环境与构建

- 安装正式版 DevEco Studio 26.0.0。
- 安装 HarmonyOS 26.0.0 SDK、模拟器、Hvigor、ohpm 和配套 Node.js。
- `compileSdkVersion` 与 `targetSdkVersion` 使用 26.0.0，`compatibleSdkVersion` 使用 5.0.0(12)。
- 使用 DevEco Studio 模拟器完成手机尺寸验证；扫码测试使用模拟器摄像头或虚拟相机输入。
- Debug HAP 使用开发调试签名。真实设备安装或应用市场发布需要用户华为开发者账号对应的证书、Profile 和正式签名。

## 测试与验收

### 领域单元测试

- 金额格式和整数分计算。
- 入货增加库存、出货减少库存以及库存不足拒绝提交。
- 重复商品数量合并和价格快照。
- 月、季度、年度及自定义日期范围边界。
- 收入、支出、毛利润、现金结余和毛利率计算。
- 扫码成功后锁定、确认后恢复、重复回调不重复入账。
- 新商品扫码入货一次确认后库存等于输入数量，不额外增加一件。

### 数据库测试

- 建库后四张业务表与索引完整。
- 入货、出货、重置事务成功和失败回滚。
- 条码唯一约束、日期和类型筛选正确。
- 修改商品价格不改变历史单据快照。

### 界面与设备验收

- 四栏导航、页面返回路径和筛选状态正确。
- 常用手机宽度下无横向溢出，关键按钮不被系统导航区域遮挡。
- 大字体下商品名称、金额和确认信息仍可读。
- 扫码识别后停止，弹窗保存后直接恢复，不出现第二次添加按钮。
- CSV 可生成并拉起系统分享面板。
- Debug HAP 可在 HarmonyOS 5.0.0 及以上兼容环境安装运行。

## 交付物

- `harmony/` 下完整 ArkTS 工程源码。
- 可安装测试的 Debug HAP。
- 环境、构建、签名和安装说明。
- 鸿蒙版功能测试记录。
- 与现有 Android 项目共同保存在同一个私人 GitHub 仓库中。

## 不在首版范围

- Android 与鸿蒙之间自动迁移数据。
- 云同步、多设备共享、账号和员工权限。
- 供应商、顾客、赊账、退货、打印小票和支付。
- 华为应用市场正式上架流程。
- 平板专属双栏布局、手表、车机和 PC 适配。
